# Котозарядка

Домашний логопедический тренажёр в виде игры для дошкольника:
дыхание, артикуляционная гимнастика, пальчиковая, гласные, звук В.

Всё содержимое занятий — в объекте `PLAN` в начале `<script>` в `index.html`.
Видео к упражнениям настраивается прямо в приложении: 👨‍👩‍👦 → «Видео к упражнениям».

Открывать по адресу GitHub Pages — из локального файла YouTube-плеер не работает (Error 153).

## Озвучка

Все фразы приложения заранее озвучены нейросетью [Silero TTS](https://github.com/snakers4/silero-models)
(модель `v4_ru`, голос `xenia`) и лежат в `audio/`. Работает офлайн, бесплатно, на процессоре.

Пересобрать другим голосом (`baya`, `kseniya`, `xenia`, `aidar`, `eugene`):

    python3 tools-озвучка.py baya

Скрипт заново создаёт `audio/` и печатает карту «фраза → файл»; её содержимое
нужно вставить в объект `AUD` в начале `index.html`.

Тянущиеся гласные («а-а-а-а») не синтезируются напрямую — скрипт берёт
установившуюся часть гласной и сшивает её по периодам голоса до четырёх секунд.

## Игры на голос

`tVoice` и `tPair` слушают микрофон и считают три величины прямо в браузере
(`initMic` в `index.html`): силу голосового тона (нормированная автокорреляция
по прореженному сигналу), спектральный центр и долю энергии в полосе 120–520 Гц.
Ни модели, ни сервера, ни интернета.

Приложение **не оценивает правильность произношения** — на детской речи с
нарушениями этого не умеет ни одна модель. Оно различает звонкий и глухой,
то есть физику, а не догадку.

Пороги берутся из калибровки по самому ребёнку (родительский экран →
«Настройка звуков»). Проверка алгоритма на синтезированных слогах пятью
дикторами: 90% при настройке на своём голосе, 85% при настройке на чужом.
